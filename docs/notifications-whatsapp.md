# Messages WhatsApp aux parents (gratuit)

L’application prépare le message et le numéro du bon parent. Un bouton ouvre
WhatsApp avec le texte déjà écrit ; la personne vérifie, modifie si besoin, puis
appuie sur **Envoyer**. Le message part du WhatsApp de l’école (téléphone ou
WhatsApp Web). Il n’y a ni abonnement, ni frais par message, ni envoi automatique.

| Message | Où le trouver |
| --- | --- |
| Absence ou retard | **Scolarité & familles → Messages WhatsApp → Absences du jour** : la liste vient de l’appel du jour (feuille de présence ou clôture du scan QR) |
| Reçu de paiement | **Factures & paiements** : bouton **Reçu WhatsApp** sur la facture, ou **Envoyer sur WhatsApp** dans la fenêtre du reçu juste après l’encaissement |
| Relance d’impayé | **Contrôle financier** : bouton **Relance WhatsApp** sur une facture avec un reste à payer |
| Annonce | **Messages WhatsApp → Annonce** (direction et administration) : à une classe, une halkha ou tous les parents |

Accès : administration, direction et comptabilité ; les annonces sont réservées
à l’administration et à la direction.

## Éviter les doublons

Chaque ouverture de WhatsApp est enregistrée avec la personne et l’heure. Un
parent déjà contacté apparaît avec une coche « Déjà ouvert par … ». L’onglet
**Journal** liste les 300 derniers messages ouverts. L’application ne peut pas
savoir si le message a réellement été envoyé dans WhatsApp : elle enregistre
l’ouverture.

## Destinataires

Chaque parent ou tuteur rattaché à l’élève a son bouton (trois au maximum), une
seule fois par numéro. Le numéro utilisé est le **numéro WhatsApp** de la fiche
parent s’il est renseigné, sinon son téléphone principal. Les numéros sénégalais
sont acceptés sous toutes les formes (`77 123 45 67`, `+221 77 123 45 67`…) ;
les fixes (33…) sont ignorés. Un numéro étranger doit commencer par `+` et
l’indicatif du pays.

Sur la carte d’un parent (**Parents & tuteurs → Modifier**), on peut saisir un
autre numéro WhatsApp ou cocher **Le parent refuse les messages WhatsApp**.

## Annonces à beaucoup de parents

Cliquer parent par parent convient pour une classe. Pour toute l’école, le plus
rapide est d’utiliser, dans l’application WhatsApp Business de l’école, une
**liste de diffusion** (jusqu’à 256 contacts) ou un groupe : les boutons
**Copier le message** et **Copier les numéros** préparent le texte et la liste.
Une liste de diffusion n’atteint que les parents qui ont enregistré le numéro de
l’école dans leurs contacts.

## Conseils

- Utilisez de préférence **WhatsApp Business** (gratuit) sur le téléphone de
  l’école, avec le nom et le logo de l’établissement.
- Sur ordinateur, connectez WhatsApp Web ou l’application WhatsApp Desktop au
  téléphone de l’école : les boutons ouvriront directement la bonne conversation.
- Faites l’appel avant de prévenir les familles : un élève corrigé en « présent »
  disparaît de la liste des absences.
